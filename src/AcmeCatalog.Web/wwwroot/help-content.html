Using the Catalog

This page is served as a standalone static document and embedded below via an <iframe>.

  • Use the category dropdown or the search box on the Catalog page to filter items without a page reload.
  • Click Quick View on any item card to preview it in a modal.
  • On desktop, drag item cards by their handle to reorder the catalog.
  • Click Load More to fetch additional items asynchronously.

This content lives at /help-content.html and is independent of the parent page.
